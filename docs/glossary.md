# 音视频术语表

> 用法：每天只追加当天真正接触过、能用自己的话解释的术语。不要一次性复制大段百科。

## Day 1

- FFmpeg：一套音视频处理工具和库集合。当前阶段先把它当作命令行工具，用来转码、抽流、截图、分析媒体文件。
- ffprobe：FFmpeg 项目里的媒体分析工具，用来查看文件里的容器、音频流、视频流、编码格式、时长、码率等信息。
- CMake：C/C++ 工程构建配置工具。后面写播放器、H.264 解析器、RTP 实验时用它生成构建工程。
- Ninja：构建执行工具。通常由 CMake 生成 Ninja 构建文件，再由 Ninja 快速编译。
- SDL2：跨平台音视频/窗口/输入库。后面写播放器时会用它创建窗口、渲染视频帧、播放音频。
